1. JavaScript简介 ​

1.1 JavaScript是什么 ​

JavaScript是一种运行在浏览器端的脚本语言，用于创建动态的网页内容。

1.2 JavaScript的特点 ​

  • 脚本语言：JavaScript是一种解释型语言，不需要编译就可以直接运行。
  • 动态语言：JavaScript是一种动态语言，可以在运行时动态地改变变量的类型和值。
  • 跨平台：JavaScript可以在不同的浏览器和操作系统上运行，只要浏览器支持JavaScript即可。

1.3 JavaScript的用途 ​

  • 动态生成网页内容：JavaScript可以动态地生成网页内容，如动态改变网页的样式、添加或删除元素等。
  • 与服务器交互：JavaScript可以与服务器进行交互，如发送HTTP请求、处理服务器返回的数据等。
  • 实现网页特效：JavaScript可以实现各种网页特效，如动画、滚动条、拖放等。

2. JavaScript的基本语法 ​

2.1 JavaScript的语法规则 ​

  • JavaScript的代码必须放在<script>标签中。
  • JavaScript的代码可以放在HTML文件的<head>部分或<body>部分。通常建议将JavaScript代码放在<body>部分的底部，以避免页面加载时出现空白。
  • JavaScript的代码可以放在单独的JavaScript文件中，然后在HTML文件中通过<script>标签引入。

2.2 JavaScript的数据类型 ​

JavaScript的数据类型包括：

  • 基本数据类型：包括数字、字符串、布尔值、null和undefined。
  • 引用数据类型：包括对象、数组、函数等。

2.3 JavaScript的变量 ​

JavaScript的变量使用var、let或const关键字声明。

javascript
var x = 10; // 声明一个变量x，并赋值为10
let y = 20; // 声明一个变量y，并赋值为20
const z = 30; // 声明一个常量z，并赋值为30

2.4 JavaScript的运算符 ​

JavaScript的运算符包括：

  • 算术运算符：包括加法、减法、乘法、除法、取模等。
  • 比较运算符：包括等于、不等于、大于、小于、大于等于、小于等于等。
  • 逻辑运算符：包括与、或、非等。
  • 赋值运算符：包括等于、加等于、减等于、乘等于、除等于等。

2.5 JavaScript的控制结构 ​

JavaScript的控制结构包括：

  • 条件语句：包括if、else if、else、switch等。
  • 循环语句：包括for、while、do while等。
  • 跳转语句：包括break、continue、return等。

2.6 JavaScript的函数 ​

JavaScript的函数使用function关键字声明。

javascript
function add(a, b) {
  return a + b;
}

2.7 JavaScript的事件处理 ​

JavaScript的事件处理使用addEventListener方法。

javascript
document.getElementById("myButton").addEventListener("click", function() {
  alert("Button clicked!");
});

3. JavaScript的DOM操作 ​

DOM（Document Object Model）是JavaScript操作HTML文档的接口。通过DOM，JavaScript可以访问和修改HTML文档的结构、内容和样式。

3.1 获取DOM元素 ​

可以使用getElementById、getElementsByClassName、getElementsByTagName等方法获取DOM元素。

javascript
var element = document.getElementById("myElement");
var elements = document.getElementsByClassName("myClass");
var elements = document.getElementsByTagName("div");

3.2 修改DOM元素 ​

可以使用innerHTML、innerText、textContent、style等方法修改DOM元素的内容和样式。

javascript
element.innerHTML = "<p>Hello, world!</p>";
element.innerText = "Hello, world!";
element.textContent = "Hello, world!";
element.style.color = "red";

3.3 添加和删除DOM元素 ​

可以使用createElement、appendChild、removeChild等方法添加和删除DOM元素。

javascript
var newElement = document.createElement("div");
newElement.innerHTML = "<p>Hello, world!</p>";
document.body.appendChild(newElement);

document.body.removeChild(newElement);

4. JavaScript的BOM操作 ​

BOM（Browser Object Model）是JavaScript操作浏览器窗口的接口。通过BOM，JavaScript可以访问和修改浏览器窗口的各种属性和方法。

4.1 获取浏览器窗口信息 ​

可以使用window对象获取浏览器窗口的各种信息，如窗口大小、滚动位置等。

javascript
var width = window.innerWidth;
var height = window.innerHeight;
var scrollX = window.pageXOffset;
var scrollY = window.pageYOffset;

4.2 打开和关闭窗口 ​

可以使用window.open方法打开一个新的浏览器窗口，使用window.close方法关闭当前窗口。

javascript
window.open("https://www.example.com");
window.close();

4.3 定时器 ​

可以使用setTimeout和setInterval方法设置定时器，在指定的时间后执行代码。

javascript
setTimeout(function() {
  console.log("Hello, world!");
}, 1000);

setInterval(function() {
  console.log("Hello, world!");
}, 1000);

5. JavaScript的事件处理 ​

事件处理是JavaScript与用户交互的重要方式。通过事件处理，JavaScript可以响应用户的操作，如点击、滚动、键盘输入等。可以使用addEventListener方法为元素添加事件监听器。

javascript
var button = document.getElementById("myButton");
button.addEventListener("click", function() {
  console.log("Button clicked!");
});

6. JavaScript的AJAX操作 ​

AJAX（Asynchronous JavaScript and XML）是一种在浏览器与服务器之间进行异步数据交换的技术。通过AJAX，JavaScript可以在不刷新页面的情况下，从服务器获取数据并更新页面内容。

javascript
var xhr = new XMLHttpRequest();
xhr.open("GET", "https://api.example.com/data", true);
xhr.onreadystatechange = function() {
  if (xhr.readyState === 4 && xhr.status === 200) {
    var data = JSON.parse(xhr.responseText);
    console.log(data);
  }
};
xhr.send();

7. JavaScript的模块化 ​

模块化是JavaScript编程的重要概念，它允许将代码组织成可重用的模块，从而提高代码的可维护性和可扩展性。JavaScript提供了多种模块化的方式，如CommonJS、AMD和ES6模块。

javascript
// CommonJS
// module.js
module.exports = {
  add: function(a, b) {
    return a + b;
  },
  subtract: function(a, b) {
    return a - b;
  }
};

// main.js
var math = require('./module');
console.log(math.add(2, 3)); // 5
console.log(math.subtract(5, 2)); // 3

// AMD
// module.js
define(['require', 'exports'], function(require, exports) {
  exports.add = function(a, b) {
    return a + b;
  };
  exports.subtract = function(a, b) {
    return a - b;
  };
});

// main.js
require(['./module'], function(math) { 
  console.log(math.add(2, 3)); // 5
  console.log(math.subtract(5, 2)); // 3
});

// ES6模块
// module.js
export function add(a, b) {
  return a + b;
}
export function subtract(a, b ) {
  return a - b;
}

// main.js
import { add, subtract } from './module';
console.log(add(2, 3)); // 5
console.log(subtract(5, 2)); // 3

8. JavaScript的异步编程 ​

JavaScript的异步编程是通过回调函数、Promise和async/await等机制实现的。回调函数是最早的异步编程方式，Promise提供了一种更优雅的异步编程方式，而async/await则进一步简化了异步编程。

javascript
// 回调函数
function fetchData(callback) {
  setTimeout(function() {
    callback('Data fetched');
  }, 1000);
}

fetchData(function(data) {
  console.log(data); // Data fetched
});

// Promise
function fetchData() {
  return new Promise(function(resolve, reject) {
    setTimeout(function() {
      resolve('Data fetched');
    }, 1000);
  });
}

fetchData().then(function(data) {
  console.log(data); // Data fetched
});

// async/await
async function fetchData() {
  return 'Data fetched';
}

async function main() {
  const data = await fetchData();
  console.log(data); // Data fetched
}

main();

9. JavaScript的函数式编程 ​

JavaScript的函数式编程是指使用函数作为一等公民的编程范式，包括高阶函数、纯函数、函数组合等概念。

javascript
// 高阶函数
function map(arr, fn) {
  return arr.map(fn);
}

const numbers = [1, 2, 3];
const doubled = map(numbers, function(n) {
  return n * 2;
});
console.log(doubled); // [2, 4, 6]

// 纯函数
function add(a, b}) {
  return a + b;
}

console.log(add(1, 2)); // 3
console.log(add(1, 2)); // 3

// 函数组合
function compose(f, g) {
  return function(x) {
    return f(g(x));
  };
}

function square(x) {
  return x * x;
}

function increment(x) {
  return x + 1;
}

const composed = compose(square, increment);
console.log(composed(5)); // 36

10. JavaScript的内存管理 ​

JavaScript的内存管理是指管理内存的方式，包括垃圾回收、内存泄漏等。

javascript
// 垃圾回收
function createPerson(name) {
  return {
    name: name
  };
}

const person1 = createPerson('Alice');
const person2 = createPerson('Bob');

// 内存泄漏
function createLeakyObject() {
  const obj = {};
  obj.self = obj;
  return obj;
}

const leakyObj = createLeakyObject();
