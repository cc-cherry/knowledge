JavaScript核心 ​

1、词法作用域和动态作用域 ​

词法作用域： 函数编写的所在的作用域，在函数定义时就已经确定

动态作用域： 函数调用时才确定，内容取决于运行时的作用域空间

2、Object.defineProperty和Proxy ​

Object.DefineProperty：

​对一个对象的某个属性的定义，添加或者是修改。可以对单个属性的进行配置，是否可写、可迭代、可配置、Get和Set等。

​缺点： 无法监听对象属性的添加删除、无法监听数组的原生方法，比如push、pop、shift等

Proxy：

​对一个对象进行读写等操作的拦截。是一个对象包装器，可以将代理上的操作转发到对象，并且可以捕获其中的一些操作。它可以包装任何类型的对象，包括类和函数。

​缺点： 具有内部插槽的内建对象(及私有字段)无法被代理（Set、Map、Date、Promise）、严格相等===无法被拦截

3、手写new ​

实例的结果：

javascript
function Person(fName, lName) {
  this.fName = fName;
  this.lName = lName;

  Person.prototype.getFullName = function getFullName() {
    return `${this.fName} ${this.lName}`;
  }
  // 如果返回对象，则仅仅是返回的对象
  // return {name: this.fName}
}

console.log(new Person('zhang', 'san'))

/**
  new的过程主要干了一下几件事
  1、创建一个新对象
  2、将父类的属性添加到实例对象身上，并初始化
  3、将原型指向父类
  4、如果父类的执行的结果是对象，则返回该对象；否则返回新创建的对象
*/

function _new2(fn, ...params) {
  // 1
  const obj = {
  // 3
   __proto__: fn.prototype
  };
  // 2 且获取执行结果
  const res = fn.call(obj, ...params);
  // 4
  return typeof res === 'object' ? res : obj;
}

function _new(fn, ...params) {
  // 1 3
  const newObj = Object.create(fn.prototype);
  // 2 且获取执行结果
  const res = fn.apply(newObj, params);
  // 4
  return typeof res === 'object' ? res : newObj;
}
console.log(_new(Person, 'zhang', 'san'))
console.log(_new2(Person, 'zhang', 'san'))
