JavaScript常见面试题 ​

1、let、const、var的区别和联系 ​

var ​

  • var是ES5声明变量的语法
  • 作用域为方法作用域，可以声明多个重复的变量
  • 声明变量但未赋值时，变量值为undefined
  • var声明的变量会进行声明提升(可以访问到变量，但是为undefined)

let ​

  • let为ES6声明变量的方式
  • let不允许声明两个重复的变量
  • 作用域为块级作用域

const ​

  • const为常量声明的方式，声明后必须进行初始化
  • const不允许对变量进行修改，或者说是对指向变量的引用的改变
  • 拥有和let一样的作用域，也不允许声明两个重复的变量

2、undefined与null ​

  • undefined表示没有任何值,表示变量未被赋值时的属性；null表示没有任何对象，typeof null为object

    • 判断某些属性是否赋值时用let abc; abc === undefined
    • undefined在布尔类型环境中为false，在数值类型中为NaN
    • null在数值类型中为0，在布尔类型中为false

  • 当某些东西没有值时，一般表示undefined

    • 函数没有返回值时，一般默认返回undefined
    • 变量未初始化时为undefined
    • 访问对象上不存在的属性时为undefined
    • Array.prototype.find() 和 Map.prototype.get() 的方法，当没有发现元素时，返回 undefined

3、forEach和map ​

  • forEach可以进行数组遍历，没有返回值，也不会影响原始对象
    • forEach不可被break
    • 执行时会自动跳过undefined值
    • [1,2,3].forEach((element,index,array) => console.log(ele,index,array))
  • map遍历数组，调用回调函数，返回新数组
    • [1,2,3].map((element,index,array) => element * 2)

4、filter ​

  • 该方法为数组的过来方法，保留回调为true的值
  • 返回数组的一部分浅拷贝
    • [1,2,3,6,7,8].filter((element,index,array) => element > 4)

8、Promise的执行顺序问题 ​

js处理任务分为两种，一是同步任务，二是异步任务。其中异步任务又分为异步微任务和异步宏任务。执行顺序同步任务>异步微任务>异步宏任务

定时器等（setTimeout/setInterval）属于异步宏任务，由宿主机发起执行，Promise.then/catch/finally()属于异步微任务，由js发起执行

JavaScript的事件循环机制：

1、所有的同步任务都在主线程上执行，形成执行栈。

2、主线程外还存在任务队列，包括宏任务队列和微任务队列，只要异步操作执行结束就会往对应的任务队列添加任务

3、只要执行栈清空(主线程上的同步任务执行完成)，js引擎就会读取并执行微任务队列中的所有任务，清空微任务队列后，再去读取并执行宏任务队列中的任务

主线程不断的重复执行上述第三个操作，这就是事件循环(Event Loop)

再看Promise的执行顺序：

javascript
setTimeout(()=>{
   console.log(1) 
})
new Promise((resolve)=>{
    console.log(2)
    resolve()
    console.log(5)
}).then(()=>{
   console.log(3) 
})
console.log(4) 
// 2 5 4 3 1

9、闭包 ​

闭包类似于类可以有自己的私有作用空间，并且可以延长变量的生命周期。闭包是方法里返回方法，在没有出现es6的class之前的隔离解决方案，闭包会常驻内存。

两个特性：

  • 变量隔离，形成私有空间
  • 延长变量的生命周期，一般函数执行完即销毁函数作用域内的变量，但是闭包会保留

vue中的data被设计为一个函数的目的：

  • 其实data()就是一个闭包，形成每个vue文件的数据隔离

数据隔离例子：

javascript
function goods(){
    let num = 1
    function add(){
        num++
    }
    return {
        ad: function(){
            add()
        },
        num: function(){
            return num
        }
    }
}
const goods1 = goods()
const goods2 = goods()
goods2.ad()

goods1.ad()
goods1.ad()

console.log(goods1.num())
console.log(goods2.num())
//结果为:  3 2

11、 原型与原型链 ​

原型 ​

每个实例对象都有一个私有属性(__proto__)称之为隐式原型，指向构造函数中的显式原型prototype，该原型对象也有一个自己的原型对象__proto__，指向上一层的原型对象，直到为null,一般为顶层(Object)

原型链 ​

当对象需要寻找一个方法或属性时，就会先在自己身上找，如果没有就去原型上找，层层往上形成一个查找链。

因为对象的原型对象层层链接，形成一个原型链。

12、作用域 ​

代码执行的上下文，值和表达式在其中能否被访问或可见。子作用域可以访问父级作用域，反之则不行。

作用域分为一下三种：

  • 全局作用域：代码运行的默认作用域
  • 模块作用域：模块模式中运行代码的作用域
  • 函数作用域：由函数创建的作用域

还有一种由let、const声明的变量的作用域：

  • 块级作用域：用一对花括号（一个代码块）创建出来的作用域

14、跨域的几种解决方案 ​

什么是跨域 ​

同源策略是一种安全协议，是浏览器为了防止他人恶意攻击网站。协议：域名：端口相同即为同源。

所以当涉及到非同源策略的数据交互时就需要跨域。

跨域的几种解决方案 ​

  • jsonp

    • 动态的插入script标签，利用url进行数据加载
    • 只能发送get请求
    • 好像百度有在用

  • 前端反向代理

    • 开发时利用webpack或者vite配置代理

    • javascript
      proxy: {
    '/api': { // 配置匹配规则/api
        target: 'http://ad.server.com',   //配置目标地址
        changeOrigin: true,   // 是否允许跨域
        pathRewrite: {
            '^/api': '/',    //配置路径重写
        },
    }
}

    • 部署时可利用nginx进行代理

  • CORS（跨域资源共享）后端配置

    • 后端(服务器端)设置 Access-Control-Allow-OriginHTTP 响应头即可

15、js的数据类型 ​

基本数据类型 ​

js的基本数据类型有：Number、String、Boolean、Null、Undefined、BigInt、Symbol（最后两个为ES6新增类型）

其中BigInt可以表示比Number更大的整数，Symbol是唯一且不可变的原始值，目的是用来创建唯一属性的键

引用数据类型 ​

引用数据类型有：Object、Array、Function、Date、RegExp、Map、Set、WeakMap、WeakSet

区别 ​

  • 基本数据类型存储在栈内存中，引用数据类型存储在堆内存中
  • 基本数据类型是按值访问的，引用数据类型是按引用访问的
  • 基本数据类型是简单的数据段，引用数据类型是由多个值构成的对象
  • 基本数据类型大小固定，引用数据类型大小不固定，因为它们可以动态添加属性

16、闭包 ​

闭包是指有权访问另一个函数作用域中的变量的函数。

闭包的作用：

  • 可以使函数内部的变量在函数执行完后，仍然存活在内存中，即闭包可以延长变量的生命周期
  • 让外部访问函数内部变量成为可能
  • 可以避免全局变量的污染

闭包的缺点：

  • 闭包会使得函数中的变量都被保存在内存中，内存消耗很大，所以不能滥用闭包，否则会造成网页的性能问题，在IE中可能导致内存泄露
  • 闭包会在父函数外部，改变父函数内部变量的值。所以，如果你把父函数当作对象使用，把闭包当作它的公用方法，把内部变量当作它的私有属性，这时一定要小心，不要随便改变父函数内部变量的值。

17、this指向 ​

this的指向在函数定义时是确定不了的，只有函数执行时才能确定this到底指向谁，实际上this的最终指向的是那个调用它的对象

this的指向可以分成以下四种情况：

  1. 作为对象的方法调用，此时this指向该对象

  2. 作为普通函数调用，此时this指向window

  3. 构造函数调用，即使用new关键字调用函数，此时this指向新创建的对象

  4. apply、call、bind调用，即使用apply、call、bind方法调用函数，此时this指向传入的第一个参数

18、深拷贝和浅拷贝 ​

浅拷贝只复制一层对象的属性，而深拷贝则复制了对象的所有层级。

浅拷贝的方法有：

  1. Object.assign()：将源对象的所有可枚举属性复制到目标对象中
  2. Array.prototype.slice()：返回一个新数组，包含原数组的所有元素
  3. Array.prototype.concat()：返回一个新数组，包含原数组的所有元素
  4. 扩展运算符（...）：返回一个新数组，包含原数组的所有元素

深拷贝的方法有：

  1. JSON.parse(JSON.stringify(obj))：将对象转换为JSON字符串，然后再将JSON字符串转换为对象
  2. 递归拷贝：遍历对象的所有属性，如果属性是对象，则递归拷贝，否则直接复制

19、原型链 ​

原型链是JavaScript中实现继承的一种机制，每个对象都有一个原型对象，通过原型链，对象可以访问到其原型对象上的属性和方法。

原型链的查找过程是从对象自身开始，逐级向上查找，直到找到属性或方法为止。

原型链的终点是Object.prototype，它是所有对象的原型对象，它包含了JavaScript中所有对象共有的属性和方法。

20、事件循环 ​

事件循环是JavaScript执行异步代码的一种机制，它通过事件队列来管理异步代码的执行。当异步代码执行完毕后，会将回调函数放入事件队列中，等待主线程空闲时执行。

事件循环的执行过程如下：

  1. 主线程执行同步代码，遇到异步代码时，将异步代码放入事件队列中
  2. 主线程执行完毕后，检查事件队列是否有待执行的回调函数
  3. 如果有，则取出回调函数执行，如果没有，则继续等待
  4. 重复步骤2和3，直到事件队列中的所有回调函数都执行完毕

21、垃圾回收机制 ​

垃圾回收机制是JavaScript中自动管理内存的一种机制，它通过标记-清除算法来回收不再使用的对象。

标记-清除算法的执行过程如下：

  1. 垃圾回收器遍历所有活动对象，将其标记为“活动”
  2. 垃圾回收器遍历所有对象，将未标记为“活动”的对象标记为“待回收”
  3. 垃圾回收器回收所有标记为“待回收”的对象，释放其占用的内存空间

垃圾回收机制可以帮助开发者避免内存泄漏，提高程序的性能。
