1、函数柯里化 ​

描述: 在数学和计算机科学中，柯里化是一种将使用多个参数的一个函数转换成一系列使用一个参数的函数的技术

例如:

javascript
  const add = (a, b) => {
    console.log(a + b);
  };

  add(1, 4) // 5
  const _add = curry(add);
  _add(1)(4); // 5

实现思路一 ​

1、先收集原函数的参数长度

2、在闭包中收集后续的所有参数

3、判断总参数长度是否大于等于原函数的参数长度

4、如果 >= 原函数的参数长度, 执行原函数

5、否则继续柯里化当前函数，并传入新的参数

javascript
  const curry = (fn, params = []) => {
    // 获取原函数的参数长度
    const length = fn.length;

    return (..._params) => {
      // 收集新参数
      const args = [...params, ..._params];
      // 比对参数个数
      if (args.length < length) {
        // 参数个数不足， 继续柯里化
        return curry.call(this, fn, args);
      } else {
        // 返回原函数的调用
        return fn.apply(this, args);
      }
    };
  };

2、实现函数链式调用 ​

描述: 函数链式调用

例如:

javascript
/**
实现一个链式调用，包含 wait、do、waitFirst 方法
waitFirst 优先级大于 wait，先执行 waitFirst，再执行前面的，再执行后面的

fn('msg')
    console.log('hello msg')

fn('msg').wait(5).do('str')
    console.log('hello msg')
    ... wait 5s
    console.log('hello str')
    
fn('msg').wait(5).do('str').do('name')
    console.log('hello msg')
    ... wait 5s
    console.log('hello str')
    console.log('hello name')
    
fn('msg').waitFirst(5).do('str').do('name')
    ... wait 5s
    console.log('hello msg')
    console.log('hello str')
    console.log('hello name')
*/

实现思路 ​

1、 利用队列数据结构对任务进行管理

2、 利用定时器宏任务最后执行任务

javascript
class Fn {
  arr = [];

  async next() {
    // 执行任务队列
    if (this.arr.length) {
      const task = this.arr.shift();
      task && (await task());
      this.next();
    }
  }

  constructor(param) {
    this.arr.push(() => {
      console.log(`hello ${param}`);
    });
    return this;
  }

  wait(time = 0) {
    this.arr.push(() => {
      // 返回 Promise 
      return new Promise(resolve => {
        setTimeout(() => {
          console.log(`...wait ${time}`);
          resolve();
        }, time * 1000);
      });
    });
    return this;
  }

  waitFirst(time = 0) {
    // 放到队头, 构造优先级队列
    this.arr.unshift(() => {
      return new Promise(resolve => {
        setTimeout(() => {
          console.log(`...wait ${time}`);
          resolve();
        }, time * 1000);
      });
    });
    return this;
  }

  do(param) {
    this.arr.push(() => {
      console.log(`hello ${param}`);
    });
    return this;
  }
}

const fn = str => {
  const chain = new Fn(str);

  // 在这里统一触发，执行下一个任务
  setTimeout(() => {
    chain.next();
  }, 0);

  // 返回当前实例
  return chain;
};

3、防抖 ​

对于频繁触发的场景进行性能优化

实现思路 ​

1、未到时间触发重新开始计时

javascript
  // 防抖
  const debounce = (fn, time) => {
    const timer = null;

    return (...args) => {
      // 清空定时器
      clearTimeout(timer);
      timer = setTimeout(() => {
        fn.apply(this, args);
      }, time);
    };
  };

4、节流 ​

对于频繁触发的场景进行性能优化

实现思路 ​

1、先执行，未到时间触发直接终止

javascript
  // 节流
  const throttle = (fn, time) => {
    const timer = null;

    return (...args) => {
      // 未到时间则终止
      if (timer) return;
      timer = setTimeout(() => {
        fn.apply(this, args);
        timer = null;
      }, time);
    };
  };
